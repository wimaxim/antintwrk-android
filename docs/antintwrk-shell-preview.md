# Оболочка и лента antintwrk — 6 октября 2026

Владелец поручил продолжить экраны, пока готовится сервер: общая оболочка, компактная верхняя навигация и лента. Реализован отдельный отладочный предпросмотр с локальными демо-данными.

## Включение

Из родительской папки мобильных проектов:

```bash
bash scripts/build-android.sh -PantintwrkOnboarding=true -PantintwrkShellPreview=true
```

Оба параметра по умолчанию выключены. Новая оболочка открывается только в debug, при включённом onboarding и отсутствии параметров внешнего входа. Она не создаёт аккаунт или сессию, не вызывает `onDone` и не меняет логику авторизации. Release игнорирует параметр shell preview. Существующие Matrix-сессии и ссылки авторизации остаются на штатном пути; `LoggedInFlowNode`, чаты и звонки не изменены.

## Реализованное поведение

- Компактная шапка с переключателем «Соцсеть · Мессенджер», без повторной строки бренда. Социальный поиск и уведомления находятся сверху, а нижняя панель содержит только «Лента · Сообщества · Профиль».
- Две локальные демо-публикации и фильтры «Рекомендации · Новое · Моя сеть», сверенные с действующей веб-лентой. Фильтры меняют состав/порядок демо-карточек. Метка предпросмотра и авторы «Demo» не выдают данные за реальные публикации.
- «Интересно»/«Не интересно» сохраняют взаимно исключающий локальный выбор. Показанный счёт — только значение этой демо-отметки, не реальная репутация или лайки других пользователей.
- Поиск работает только по локальным демо-текстам на текущем языке, включая отсутствие результатов. Уведомления, комментарии и отправка публикации показывают честное состояние ожидания серверной интеграции.
- Сообщества и профиль имеют самостоятельные места в навигации и состояния ожидания подключения аккаунта. Это ещё не реализация каталогов или редактирования профиля.
- Переключатель мессенджера показывает состояние ожидания подключения аккаунта. Реальный мессенджер в эту оболочку ещё не встроен; его исходные экраны сохранены. Не создаётся имитация чатов, звонков или непрочитанных сообщений.
- При переходах сохраняются выбранный социальный раздел, фильтр, прокрутка и локальные отметки. Back закрывает окно, возвращает из мессенджера к прежнему социальному разделу, из других социальных разделов — к ленте; на корневой ленте остаётся штатный системный выход.

Состояние разделов и фильтра использует `rememberSaveable`; содержимое разделов изолировано `SaveableStateHolder`. Пароли и токены в оболочке отсутствуют. Новый код не обращается к серверу соцсети или Matrix.

## Проверки первого этапа

Сборка debug APK и обе проверки ktlint прошли. Прошло 16 целевых тестов: пять новых Compose UI-тестов оболочки, четыре presenter-теста входа, три UI-теста входа, два теста системных панелей и два штатных теста внешних Matrix-ссылок. Проверены поиск без результатов, закрытие уведомлений, сохранение раздела/фильтра/отметки, отсутствие социальных действий в мессенджере и сохранение позиции ленты на маленьком окне 320×480 dp.

APK установлен на эмулятор API 36 arm64. Английская лента просмотрена при светлой системной теме: интерфейс остаётся тёмным, системные значки видны. Четыре критерия: основные действия доступны (удобство); иерархия и палитра согласованы с соцсетью (композиция); состояния явно отделяют демо от реального аккаунта (понятность); поиск/уведомления не дублируются снизу и нет лишней строки бренда (отсутствие перегрузки).

У первого этапа 29 новых английских строк. Локализация остальных восьми языков выполняется следующим отдельным коммитом. Снимки и APK находятся вне Git в `../artifacts/android/shell/`; тесты не записывают снимки. Проверка реальных данных, серверных ошибок, авторизации, переписки и звонков невозможна без инфраструктуры и не считается выполненной.
