# Оболочка и лента antintwrk — 6 октября 2026

## Реальная веб-лента — третий этап

Реальная лента с `https://antintwrk.com/LANG/hero-feed?app=1` подключена отдельным debug-флагом. Сайт отдаёт представление без общей шапки, подвала и боковых колонок; карточки и их контроллеры переиспользуются. Нативные переключатель, поиск/уведомления и три нижних раздела сохранены. Поиск открывает `/LANG/discover?app=1`; сообщества, профиль и уведомления ещё ожидают интеграции. С выключенным флагом доступна прежняя демолента. Штатные маршруты Matrix не изменены.

Сборка из общего корня: `bash scripts/build-android.sh -PantintwrkOnboarding=true -PantintwrkShellPreview=true -PantintwrkWebFeed=true`. Java21 из Android Studio, SDK/API36 arm64. Origin задан централизованно в appnav BuildConfig. Флаг по умолчанию false и применяется только при DEBUG; релизный вход ещё не подключён.

По прямому поручению владельца сейчас гостевой доступ для разработки. После подключения авторизации приложение и социальные разделы доступны ТОЛЬКО авторизованным; гостевой просмотр остаётся только в обычном вебе. Контроль обязателен на клиенте и сервере. `app=1` не является авторизацией, существующая веб-сессия не является готовой общей сессией antintwrk/Matrix.

WebView сохраняет экземпляр и позицию при переключении разделов; системный Back использует его историю. Разрешённые внутренние HTTPS-маршруты получают app=1 с сохранением query/fragment. Первая служебная cookie-проверка движка проходит внутри WebView для разрешённого назначения. Внешний переход требует действия пользователя. Нет JS bridge; file/content URI, mixed content и сторонние cookie запрещены. Ошибка основного документа показывает нативную кнопку повтора, ошибка subresource не скрывает документ.

Проверки выполнены: debug APK собран; 23 целевых теста прошли с включёнными и выключенными флагами; appnav/app ktlint прошли; по 58 собственных XML-ключей совпадают на девяти языках. Шесть новых тестов проверяют origin/локали, query/fragment, блокировку недопустимых путей, первый визит, HTTP503/повтор и сохранение экземпляра WebView с настройками. Тесты не записывают снимки.

На эмуляторе API36 просмотрены реальные публикации RU/EN/AR, свежий первый запуск, ошибка при отключении сети, RU320dp со шрифтом150%. Обнаруженное обрезание длинного заголовка исправлено в app-CSS сайта и повторно проверено. Четыре критерия: панели доступны и есть повтор (удобство); тёмная палитра и помещающиеся карточки (визуальная структура); ясный текст ошибки (понятность); одна общая навигация (нет перегрузки).

Артефакты вне Git: `../artifacts/android/web-feed/antintwrk-web-feed-arm64-debug.apk`, `feed-ru.png`, `feed-ru-narrow.png`, `feed-en.png`, `feed-ar.png`, `offline-ru.png`, журналы сборки/тестов и HTTP-проверок. Debug package и подпись исходные; это проверочная сборка. Нет авторизации, восстановления WebView после уничтожения процесса и проверки реальных Matrix-аккаунтов. TalkBack, клавиатура, действия реальных карточек, Back/поиск на устройстве и окончательная браузерная приёмка ещё требуют проверки. Чек-лист сайта — `QSNEmain/projects/heroworld.org/codex/antintwrk.md`. Исторические этапы ниже сохранены.

Владелец поручил продолжить экраны, пока готовится сервер: общая оболочка, компактная верхняя навигация и лента. Реализован отдельный отладочный предпросмотр с локальными демо-данными.

## Включение

Из родительской папки мобильных проектов:

```bash
bash scripts/build-android.sh -PantintwrkOnboarding=true -PantintwrkShellPreview=true
```

Оба параметра по умолчанию выключены. Новая оболочка открывается только в debug, при включённом onboarding и отсутствии параметров внешнего входа. Она не создаёт аккаунт или сессию, не вызывает `onDone` и не меняет логику авторизации. Release игнорирует параметр shell preview. Существующие Matrix-сессии и ссылки авторизации остаются на штатном пути; `LoggedInFlowNode`, чаты и звонки не изменены.

## Реализованное поведение

- Компактная шапка с переключателем «Соцсеть · Мессенджер», без повторной строки бренда. Социальный поиск и уведомления находятся сверху, а нижняя панель содержит только «Лента · Сообщества · Профиль».
- Две локальные демо-публикации и фильтры «Рекомендации · Новое · Моя сеть», сверенные с действующей веб-лентой. Фильтры меняют состав/порядок демо-карточек. Метка предпросмотра и авторы «Demo» не выдают данные за реальные публикации.
- «Интересно»/«Не интересно» сохраняют взаимно исключающий локальный выбор. Показанный счёт — только значение этой демо-отметки, не реальная репутация или лайки других пользователей.
- Поиск работает только по локальным демо-текстам на текущем языке, включая отсутствие результатов. Уведомления, комментарии и отправка публикации показывают честное состояние ожидания серверной интеграции.
- Сообщества и профиль имеют самостоятельные места в навигации и состояния ожидания подключения аккаунта. Это ещё не реализация каталогов или редактирования профиля.
- Переключатель мессенджера показывает состояние ожидания подключения аккаунта. Реальный мессенджер в эту оболочку ещё не встроен; его исходные экраны сохранены. Не создаётся имитация чатов, звонков или непрочитанных сообщений.
- При переходах сохраняются выбранный социальный раздел, фильтр, прокрутка и локальные отметки. Back закрывает окно, возвращает из мессенджера к прежнему социальному разделу, из других социальных разделов — к ленте; на корневой ленте остаётся штатный системный выход.

Состояние разделов и фильтра использует `rememberSaveable`; содержимое разделов изолировано `SaveableStateHolder`. Пароли и токены в оболочке отсутствуют. Новый код не обращается к серверу соцсети или Matrix.

## Проверки первого этапа

Сборка debug APK и обе проверки ktlint прошли. Прошло 16 целевых тестов: пять новых Compose UI-тестов оболочки, четыре presenter-теста входа, три UI-теста входа, два теста системных панелей и два штатных теста внешних Matrix-ссылок. Проверены поиск без результатов, закрытие уведомлений, сохранение раздела/фильтра/отметки, отсутствие социальных действий в мессенджере и сохранение позиции ленты на маленьком окне 320×480 dp.

APK установлен на эмулятор API 36 arm64. Английская лента просмотрена при светлой системной теме: интерфейс остаётся тёмным, системные значки видны. Четыре критерия: основные действия доступны (удобство); иерархия и палитра согласованы с соцсетью (композиция); состояния явно отделяют демо от реального аккаунта (понятность); поиск/уведомления не дублируются снизу и нет лишней строки бренда (отсутствие перегрузки).

У первого этапа 29 новых английских строк. Второй этап добавляет их переводы на восемь остальных языков. Снимки и APK находятся вне Git в `../artifacts/android/shell/`; тесты не записывают снимки. Проверка реальных данных, серверных ошибок, авторизации, переписки и звонков невозможна без инфраструктуры и не считается выполненной.

## Локализация и адаптация — завершённый второй этап

Оболочка переведена на `en`, `ru`, `uk`, `de`, `es`, `fr`, `it`, `ar`, `zh`. XML и совпадение ключей проверены: по 56 собственных строк вместе с предыдущими формами авторизации в каждом из девяти наборов. Upstream-каталоги не изменены.

Лента запущена на всех девяти языках на эмуляторе API 36 arm64; снимки просмотрены. После обнаружения неудачных переносов шапка адаптирована: при ширине менее 360 dp или шрифте больше 120% переключатель занимает всю ширину, поиск и уведомления располагаются отдельной строкой. Нижние подписи используют размер Compound XS и полную ширину своего раздела. После исправления проверены русский, немецкий и арабский на ширине 320 dp со шрифтом 150%; лента прокручивается, фильтры горизонтально прокручиваемые. Это не проверка всех возможных размеров и масштабов.

Финальная сборка debug APK прошла. Прошло 17 целевых тестов с включёнными флагами и ещё раз с выключенными; обе проверки ktlint прошли. Шестой UI-тест оболочки проверяет найденную публикацию, регистр и пробелы поискового запроса. Тест отметки сначала прокручивает к действию, чтобы нажимать видимую кнопку на маленьком тестовом окне.

С выключенными флагами собран и установлен APK: просмотрено исходное приветствие Element. На реальных Matrix-аккаунтах вход, криптография, переписка и звонки пока не проверены. Буфер crash log эмулятора пуст. Восстановление после уничтожения процесса, TalkBack, клавиатура и диалоги на устройстве остаются отдельной проверкой.

Артефакты финального предпросмотра: `../artifacts/android/shell/antintwrk-shell-preview-arm64-debug.apk`, `feed-ru.png`, `feed-ru-narrow.png`, `original-matrix.png` и журналы языковых запусков. Сборка воспроизводится командой выше с Java 21 из Android Studio и установленным Android SDK. APK использует исходный debug package и тестовую подпись; он не предназначен для выпуска.
